# 🧑‍🏫 Teacher Management Interface

A modern, responsive, and accessible Teacher Management Interface built using **Next.js**, **TypeScript**, and **Tailwind CSS**. This application focuses on delivering a clean UI, seamless user experience, and adheres to modern frontend development standards.


## 📚 Project Overview

This project is part of a frontend vendor assignment to showcase skills in building a responsive, component-based UI system for managing teacher profiles and payments.

### 🎯 Objective

- Build a user-friendly and modern Teacher Management interface.
- Use TypeScript, Next.js, and Tailwind CSS.
- Implement responsive design, accessibility, validation, and clean UI components.

---

## 🧩 Features

✅ Fully responsive and mobile-first

## 🔧 Setup & Installation

```bash
# Clone the repo
git clone https://github.com/manikandanravi/teacher-management-ui.git
cd teacher-management-ui

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run start
✨ Key Screens / Pages
Route	Description
/	Landing / Overview page
/teachers	Teachers list / management dashboard
/payments	Payment form with validation
/success	Feedback page (success/error states)

💡 Design & Implementation Decisions
Tailwind CSS for utility-first, responsive design with rapid development.

TypeScript for robust type-checking and code maintainability.

Component-based structure to maximize reusability and readability.

Accessibility-first approach using semantic HTML and WCAG guidelines.

Micro-interactions and transitions using Tailwind's animation utilities.

🧪 Accessibility Compliance
✅ Semantic HTML

✅ Keyboard navigable

✅ Color contrast checks

✅ Focus ring support

✅ ARIA roles for dynamic components

📌 Assumptions
Mock data is used in place of real APIs.

Payment form is frontend-only and simulates validation logic.

UI decisions are based on best practices, extrapolated from limited mockup inputs.
